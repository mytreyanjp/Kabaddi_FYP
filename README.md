# Kabaddi_FYP

Kabaddi first phase

Analysis with numeric data from PKL matches.

## Key Objectives
- Optimal team selection for Tamil Nadu state team (**Tamil Thalaivas**)  
  - Heuristic selection  
  - Integer Linear Programming (ILP) approach  

- Strategy recommendations for each player  
  - Based on historical performance against every other team  
  - MDL-based analysis
